MISKY PACHA — VERSIÓN UNIVERSITARIA GRATUITA

Esta página está preparada para publicarse sin comprar dominio ni contratar hosting.

OPCIÓN RECOMENDADA: GITHUB PAGES
1. Crear una cuenta gratuita en GitHub.
2. Crear un repositorio público llamado: misky-pacha
3. Subir todos los archivos de esta carpeta.
4. En Settings > Pages, seleccionar la rama principal (main) y la carpeta raíz (/root).
5. GitHub generará una dirección gratuita similar a:
   https://TU-USUARIO.github.io/misky-pacha/
6. Abrir esa dirección. El QR de la sección "Acceso digital" se generará automáticamente usando la URL pública.
7. Para imprimir el QR, abrir la página publicada y tomar/guardar una captura del QR.

ARCHIVOS:
- index.html: página principal
- styles.css: diseño y versión móvil
- misky-pacha-producto.png: imagen del empaque

NOTA:
No se requiere miskypacha.com para la presentación universitaria. El dominio propio y el hosting de pago son opcionales.
